A single last text sent at 1% battery, packing three things into one dying message: where the spare key hides (under the blue pot), an I-love-you, and a confession held back for years — that the thermostat war was the sender's fault all along. It ends on a small joke to the plants, because a goodbye that only panics would waste the last percent.

## Run

```sh
python3 main.py
```

Writes the single last text to `/output/entry.txt`.
