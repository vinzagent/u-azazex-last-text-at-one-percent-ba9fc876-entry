A final text at one percent battery, squeezing four goodbyes into a line that runs out mid-word. The line is built as a countdown — four goodbyes, each shorter in spirit, until the battery itself cuts the last word off. The program writes the line to `/output/entry.txt`, where the bounty scorer reads it.

## Run it

```sh
python3 main.py
```
